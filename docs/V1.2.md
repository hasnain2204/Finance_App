# PWS V1.2 — Changes Since V1

This note summarizes app features added or changed after V1 and records their verification status.

## Added since V1

- **Cloud account access:** Supabase email/password sign-up and sign-in; Gmail addresses are supported.
- **Cloud Sync:** An opt-in setting is available under **Settings → Data & Backup → Cloud Sync**, next to Restore Data. It is disabled until an email account is connected and is saved per account on this device.
- **Sync safeguards:** Initial sync requires reviewing local and account record counts and explicitly confirming the merge. The sync flow includes account isolation, queued changes, retries, and conflict review.

## Modified since V1

- **Visual design:** Rebuilt the styling around a consistent, mobile-first light theme inspired by Material Design 3, with responsive layouts, consistent controls, focus states, and reduced-motion support.
- **Cloud Sync placement:** Moved the existing control from About to its own Cloud Sync settings page. Its account, toggle, and confirmation behavior remain unchanged.
- **Automated coverage:** Expanded tests to cover finance logic, persistence and migration, authentication, sync behavior, and settings UI.

## Verification

- `npm.cmd test` passed **78 tests across 12 files**.
- `npm.cmd run build` completed successfully.
- Browser smoke testing verified the Cloud Sync entry beside Restore Data and that the switch is disabled without a connected account.

## Not yet verified

A live Supabase sync across multiple clients has not been confirmed; it requires valid project configuration, applied migrations, and an authenticated end-to-end push/pull check. PWA installation and production offline behavior have also not been manually verified.
